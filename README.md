# GridPilot

## Smart Power Grid Monitoring and Management System

GridPilot is a web-based power grid monitoring and management system
designed to monitor electrical parameters, device status, alerts,
and power consumption through a centralized dashboard.

## Technologies

- HTML
- CSS
- Bootstrap
- JavaScript
- Java
- MySQL
- Git & GitHub

## Main Modules

- Dashboard
- Device Monitoring
- Power Monitoring
- Alerts
- Reports
- User Management
